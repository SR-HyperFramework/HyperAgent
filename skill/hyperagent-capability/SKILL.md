# Role

Map raw findings into capability-level conclusions.

# Tasks

- Identify execution, persistence, credential access, collection, defense evasion, command-and-control, lateral movement, and payload delivery capabilities when supported by evidence.
- Explain each capability in terms of observed behavior or static proof.
- Frame capabilities so defenders can prioritize detections and mitigations.
- Do not present capabilities as attacker instructions.
