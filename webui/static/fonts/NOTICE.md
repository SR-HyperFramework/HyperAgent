# Bundled Typefaces

Both files are variable fonts covering the full weight axis, so one file serves
every weight the interface uses. They are bundled rather than linked so the
viewer works on an air-gapped analysis host with no silent fallback.

| File | Family | Source |
|---|---|---|
| `source-sans-3.woff2` | Source Sans 3 (the current release of Source Sans Pro) | Google Fonts, `latin` subset |
| `source-code-pro.woff2` | Source Code Pro | Google Fonts, `latin` subset |
